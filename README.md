# 未然 · 校园健康

> 首届校园 AI Agent 创新大赛 · 赛道二「AI+校园服务」参赛原型。
> 用小球视图把饮食、作息、运动三类校园健康数据与校医预约收进同一个界面，主打「防患于未然」。

## 在线访问

- 线上站点：https://xiaotong-campus.app.workbuddy.host/?sharecode=J7SOPQ2ENF
- 演示账号：`20260101 / 123456`（另有 20260102、20260201、20260202，同密码）

## 数据与隐私

**全部为虚构脱敏模拟数据**：学生以「同学A/B/C」代称，演示学号、医生、时段、健康档案均为模拟值；
不接入任何真实校园系统、不收集真实个人信息。30 条高频问答存于 WorkBuddy 云数据库 `campus_faqs`
（公开只读 RLS），前端在云端不可用时自动降级到 `faqs.js` 本地镜像；预约记录只写浏览器 localStorage。

## 技术形态

纯静态站点，无构建、无框架。`index.html` + 多层 CSS + 多个 JS 按层叠顺序加载，
后加的样式层只覆盖自己职责范围内的规则；三个全局钩子 `XT_ORB` / `XT_CHAT` / `XT_DRAWER`
串起小球视图、对话流与手机抽屉的联动。

| 端 | 布局 | 引导 |
|---|---|---|
| 桌面 ≥1024px | 左 380px 对话 + 右小球舞台 | 蓝→青绿渐变主文案 |
| 手机 ≤1023px | 全屏球舞台 + 76vh 底部抽屉 | 「防患于未然」+ 功能说明 + 球下标签 |

## 本地运行

```bash
cd 项目根目录
python -m http.server 8123 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8123/index.html
```
