## 10 分钟极速复现指南

> 项目**无构建、无框架、无第三方运行时依赖**，不需要 `npm install`、不需要安装数据库、不需要申请任何密钥。

### 第 1 步 · 取代码（约 1 分钟）

```bash
git clone https://github.com/Yanyun-a1/weiran-campus-health.git
cd weiran-campus-health
```

### 第 2 步 · 起本地静态服务（约 10 秒）

```bash
python -m http.server 8123 --bind 127.0.0.1
# Windows 若只有 py 启动器： py -m http.server 8123 --bind 127.0.0.1
```

### 第 3 步 · 打开页面（约 5 秒）

浏览器访问 `http://127.0.0.1:8123/index.html`，用 `20260101 / 123456` 登录。
首次进入会依次走**登录 → 知情同意 → 首次推荐**三道门禁，之后由 `localStorage` 记住，不会重复弹出。

### 第 4 步 · 按场景走一遍闭环（约 5 分钟）

| 场景 | 桌面 ≥1024px | 手机 ≤1023px |
|---|---|---|
| 看状态 | 右栏点「食序 / 息衡 / 动跃」大球 → 三段式分裂到中球层 → 点子球看详情 | 全屏球舞台点大球；球下有「饮食 / 作息 / 运动」标签 |
| 问问题 | 左栏输入「食堂几点开饭」或点快捷入口（30 条问答 / 10 分类） | 底部 52px 把手上拉展开 76vh 抽屉；点「去点球 →」收起抽屉并高亮对应球 |
| 约校医 | 点中心「校医院」球 → 医生列表 → 选医生 → 复用请假表单预填时段 → 提交生成预约凭证卡 → 「我的预约」查记录 | 同左 |

### 第 5 步 · 复跑验收（可选，约 3 分钟）

```bash
# 需要本机另起一个带调试端口的 Chrome：
# chrome.exe --headless=new --remote-debugging-port=9222 --user-data-dir=<临时目录> about:blank
node tests/e2e-v28.js                    # 本地 50/50
node tests/e2e-v28.js "https://xiaotong-campus.app.workbuddy.host/?sharecode=J7SOPQ2ENF"   # 线上 50/50
```

> 云端不可用时无需任何配置：前端会自动降级到随站点发布的 `faqs.js` 本地镜像（同样 30 条问答），功能不中断。

## 技术形态

分层静态架构：`index.html` + 10 层 CSS 按 `styles → orb-view → split → gate → doctors → polish → bg-v2 → v25 → v26 → v27 → v28` 顺序叠加，脚本按序加载，**后加层只覆盖自身职责**。三个全局钩子 `XT_ORB` / `XT_CHAT` / `XT_DRAWER` 串起小球视图、对话流与手机抽屉的联动。

| 端 | 布局 | 引导 |
|---|---|---|
| 桌面 ≥1024px | 左 380px 对话区 + 右小球舞台 | 单行蓝→青绿渐变主文案（40px 基准、按容器自动降字号） |
| 手机 ≤1023px | 全屏球舞台 + 76vh 底部抽屉 | 「防患于未然」+ 功能说明行 + 球下标签 +「去点球 →」 |

核心技术（详见 [`docs/技术文档.pdf`](docs/技术文档.pdf)）：JS 逐帧球面投影 `--px/--py/--sc`、玻璃五层质感配方、三段式分裂动画、中心「校医院」球与三条流动虚线、`pointer + rAF` 抽屉拖拽、真实时间驱动的医生排班（`doctorState / nextShiftStart / relTime / bookingPreset`）、云数据库公开只读 RLS 与三层降级、`:has()` 拖动性能守卫、CDP 真浏览器 E2E 与 SHA256 基线。

## 数据与隐私边界

**全部业务数据为虚构脱敏模拟值**：学生以「同学 A/B/C」代称，演示学号、医生姓名、排班时段、健康档案均为模拟值；**不接入任何真实校园系统、不收集真实个人信息**。
30 条问答存于云端 `campus_faqs`（公开只读 RLS），云端不可读时降级到 `faqs.js`；预约记录只写浏览器 `localStorage`，换设备不共享。本项目为参赛作品，不作为生产系统使用。
