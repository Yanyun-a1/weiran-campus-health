# v6 · 小球改为 JS 逐帧投影

- 时间：2026-11-11 00:47:41 (GMT+8)
- 状态：未发布

## 目标

彻底删除 CSS 3D 旋转（会把球压成椭圆），位置 / 大小 / 层级全部由 JS 每帧计算。

## 主要改动

- 球只做 translate3d + scale：球面坐标 → 绕 Y → 绕 X → k=d/(d-z2) → px/py/sc
- t=(z2+R)/2R 归一化驱动 opacity / filter / z-index；rAF 节流、500ms 缓动、8px 点击阈值
- 外壳 radial-gradient 加 closest-side，边缘光才落在可见圆内

## 验收

- e2e-v6 本地 19/19 PASS；球宽高比 1.0000，拖动全程无旋转矩阵分量
