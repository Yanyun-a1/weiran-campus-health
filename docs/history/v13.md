# v13 · 修移动端点中球详情闪退

- 时间：2026-11-11 12:45:15 (GMT+8)
- 状态：已发布

## 目标

只修一个 bug：手机点中球后详情面板闪一下立刻消失。

## 主要改动

- 根因：打开详情的同一次手势，pointerup 后补发的 click 命中刚显示的遮罩
- 移除 document click 对遮罩的判定，改在遮罩元素上绑 pointerdown / pointerup
- 三道保护：350ms 冷却期、起终点都在遮罩自身、isAnimating 守卫
